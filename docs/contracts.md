# Контракты между приложениями

`mc-build-updater` читает публичный HTTP API `file-hosting`. Старые GET-маршруты сохраняются для уже выпущенных клиентов.

## Базовый URL

| Режим | URL |
| --- | --- |
| Dev (`--dev`) | `http://localhost:1447/` |
| Production | `http://mc.sinezix.ru:1447/` |
| Переопределение | только production: `--file-hosting-url <URL>` |

Клиент нормализует отсутствие завершающего `/`. В `--dev` `--file-hosting-url` игнорируется, поэтому localhost обязателен. `MC_BU_FILE_HOSTING_URL` не поддерживается.

## Публичное чтение

Все маршруты ниже принимают только `GET`.

| Маршрут | Ответ | Назначение |
| --- | --- | --- |
| `/map/update` | `200`, пустое тело | Пересканировать `files/`, синхронизировать SQLite-карту. |
| `/map/version` | JSON-строка | Версия карты. Меняется только при изменении файлов. |
| `/map` | `FileMap[]` | Полная карта опубликованных файлов. |
| `/map?dir=<dir>` | `FileMap[]` | Файлы в каталоге и его подкаталогах. |
| `/map?branch=<branch>` | `FileMap[]` | Файлы, на которые ссылается `MM/<branch>.json`. |
| `/map?dir=<dir>&branch=<branch>` | `FileMap[]` | Пересечение фильтров. |
| `/<dir>/<sha1>` | файл | Скачать по SHA-1. |
| `/<dir>/<name>` | файл | Скачать по имени. |

При отсутствующем JSON манифеста ветки `/map?branch=` возвращает `404`; при ссылке на несуществующий hash — `409`. Небезопасные query-параметры — `400`.

Манифест ветки `MM/<branch>.json` — JSON-массив объектов с `hash` и `path`. `path` задаёт тематическую зону и имя файла: `mods/<name>`, `resourcepacks/<name>` или `shaderpacks/<name>`. При запросах с `branch` server отбирает файлы по `hash`, а `dir` ограничивает их тематическим каталогом.

Выдача файлов поддерживает стандартный `Range`. Корректный запрос `Range: bytes=start-end` получает `206 Partial Content`, `Content-Range` и `Accept-Ranges`.

### `FileMap`

```json
{
  "hash": "50c64ec7245c3f76a563d64c85e6ca3d549b1828",
  "path": "X:\\...\\files\\mods\\example.jar",
  "name": "example.jar",
  "dir": "mods",
  "size": 7340032
}
```

`hash` — SHA-1 содержимого в lowercase hex. `path` — абсолютный путь server и не предназначен для клиента. `dir` — относительный каталог с `/`; `size` — размер в байтах. Старые клиенты могут игнорировать добавленное поле `size`.

## API записи

Все операции записи требуют:

```http
Authorization: Bearer <FILE_HOSTING_TOKEN>
```

Сервер получает токен из `FILE_HOSTING_TOKEN`. При пустом значении запись отключена (`503`); неверный или отсутствующий bearer-токен — `401` и `WWW-Authenticate: Bearer`.

| Маршрут | Успех | Назначение |
| --- | --- | --- |
| `PUT /api/files/<relative-path>` | `201` создан, `204` заменён или идентичен | Потоково загрузить файл. |
| `DELETE /api/files/<relative-path>` | `204` | Удалить файл; отсутствующий — `404`. |

Путь должен быть относительным к `files/`, без `..`, абсолютных путей и `\`. Разрешены любые опубликованные зоны, включая `mods/`, `MM/`, `config/`, `static/`. SQLite-файл и его `-wal`/`-shm` зарезервированы. PUT создаёт промежуточные каталоги, записывает временный файл и атомарно заменяет цель. Изменение сразу обновляет SQLite, `/map`, `/map/version` и обычную выдачу.
